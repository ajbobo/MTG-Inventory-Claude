# MTG Inventory

A web-based Magic: The Gathering card inventory tracker that allows users to:
- Select MTG sets to view available cards
- Display card details with mana cost symbols
- Track card quantities across different variants
- Save quantities locally using browser storage

## Features
- Responsive card display with mana cost visualization
- Quantity tracking for different card variants (normal, foil, prerelease, autographed)
- Local storage persistence for quantities
- Set selection with card icons
- Mobile-friendly responsive design

## Technologies Used
- HTML/CSS/JavaScript
- Scryfall API for card data
- LocalStorage for persistent quantities
- Font Awesome for icons

## Installation
1. Clone the repository:
```bash
git clone https://github.com/your-username/mtg-inventory.git
cd mtg-inventory
```

2. Open `index.html` in your browser

## Usage
1. Select a set from the dropdown to view available cards
2. Click on any card to view detailed information
3. Adjust quantities using the input fields
4. Quantities will automatically save to your browser
